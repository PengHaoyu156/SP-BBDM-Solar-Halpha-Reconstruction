A.1 VQGAN-f4 Autoencoder
The BBDM-f4 series models operate in the latent space of a pretrained VQGAN-f4 autoencoder. The input image is first encoded into a latent feature map with a downsampling factor of 4, and the Brownian-bridge diffusion process is then performed in this latent space. The VQGAN autoencoder used in this study is initialized from the checkpoint vq-ldm-f4.ckpt and is kept frozen during the training of Baseline BBDM-f4, BBDM-f4+Lgrad, and SP-BBDM. The VQGAN encoder–decoder uses a base channel number of 128, channel multipliers of (1,2,4), and two residual blocks at each scale. No self-attention layer is used in this autoencoder.
A.2 Latent BBDM U-Net
The latent denoising network in BBDM-f4 is implemented as a U-Net and operates on three-channel latent feature maps. The U-Net uses a base channel number of 128 and channel multipliers of (1,4,8), corresponding to feature-channel numbers of 128, 512, and 1024 at the main resolution scales. Each scale contains two residual blocks. Self-attention is applied at latent resolutions of 32, 16, and 8, with 8 attention heads and a head dimension of 64. The network uses scale-shift normalization and residual up/downsampling blocks, but does not use a spatial transformer module. Baseline BBDM-f4 and BBDM-f4+Lgrad use the same VQGAN autoencoder and latent U-Net backbone.
A.3 Stage-1 Training Configuration
The stage-1 BBDM-f4-based models are trained for 60,000 steps using the Adam optimizer with a learning rate of 2×10−4, β1=0.9, and weight decay set to 0. The training batch size is set to 8, and two-step gradient accumulation is used to reduce GPU memory consumption. Exponential moving average (EMA) is enabled during training, with a decay coefficient of 0.995. EMA updates start from step 4000 and are performed every 16 steps. During inference, the diffusion models are evaluated using linear skip sampling with 200 sampling steps and η=0, corresponding to deterministic sampling.
A.4 ROI-Guided Residual Refinement Module
The second-stage REF module is implemented as a NAFNet-style ROI residual refiner. Its input is the concatenation of the AIA 304 Å image patch, the Hα patch reconstructed by the first stage, and the ROI soft mask, resulting in 7 input channels. The module predicts a three-channel residual correction, and the mask-weighted residual is added back to the first-stage coarse reconstruction to obtain the refined image patch.
The REF network uses a channel width of 32, 4 middle blocks, encoder block numbers of (2,2,4), and decoder block numbers of (2,2,2). REF is trained on 96×96 ROI patches cropped from full-disk images, with 4 ROI patches sampled from each image. The ROI mask is determined from the union of structural cues derived from the AIA image and the first-stage reconstruction, using brightness, gradient, and local-contrast thresholds. In the REF loss, the reconstruction-related loss terms, gradient loss, and Sobel loss are weighted by the ROI mask, with a mask-boosting factor of 3.0 to increase the optimization weight of the selected ROI regions.
A.5 pix2pix Baseline Configuration
The pix2pix baseline is trained under the aligned paired image-to-image translation setting, with the mapping direction AtoB corresponding to AIA 304 Å to Hα. The input follows the standard AB concatenation format, where the left half is the AIA 304 Å image and the right half is the corresponding Hα image. The generator is U-Net 256, and the discriminator is the basic 70 × 70 PatchGAN. The training objective consists of vanilla GAN loss and L1 loss, with the L1 loss weight set to λL1=100. The Adam optimizer is used with a learning rate of 2×10−4, β1=0.5, and a batch size of 1. The model is trained for 100 epochs, followed by 100 epochs of linear learning-rate decay. Since the images are preprocessed to the target resolution before training, the pix2pix preprocessing option is set to none. Horizontal flipping is enabled during training to keep the augmentation setting consistent with the BBDM-f4 series.
A.6 Restormer Baseline Configuration
Restormer is trained as a deterministic image-to-image restoration baseline using the same training, validation, and test splits as the other models. The model adopts the base channel dimension (dim=48) from the original Restormer configuration. Due to GPU memory limitations, both the training batch size and validation batch size are set to 1, and four-step gradient accumulation is used, resulting in an effective batch size of 4. The Adam optimizer is used with a learning rate of 2×10−4, β1=0.9, and weight decay set to 0. The maximum number of training steps is set to 40,000.
